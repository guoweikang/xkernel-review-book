## 3. P04 深读带来的明确修正

P04 已将收益、成本和风险作为推荐动机，使用已重构和未重构克隆训练分类器。
III.E 对未重构样本进行下采样，使其与已重构样本数量相等；III.F 指出部分特征由人工提取，
并因获取成本回避某些潜在特征。这意味着不能只比较模型推理成本，也不能把平衡样本效果直接外推自然分布。

作者在有效性威胁中明确承认历史重构不一定是长期质量上的最佳选择，开发者可能只处理容易改的部分，
并讨论专家标注及其偏差。因此“注意历史标签不是绝对真值”本身也不能当作新发现。
本项目应采用的具体措施是：未改代码保持未知，不自动标为不值得改；保留合理独立、部分共享与多方案标签，
计入人工提取/核验成本，并将诊断集与自然分布结果分开报告。这是协议取舍，尚未验证其效果。

## 4. 首个聚焦问题：关键证据不足时，如何作出有用的共享判断？

建议优先细化原 H1，而不是同时开发完整自动重构系统。

**待检验问题：** 对相同候选及相同可访问材料，显式区分共同机制、定制差异、关键未知与证据冲突，
并只请求会改变当前决定的补证，能否在同等核验预算下增加被确认的有效建议，而非只增加弃答？

候选机制草案：将一项具体共享方案的前提绑定到证据；缺失/冲突先定位到影响的前提，
再选择补证、缩小共享范围、换方案或保留独立。补证选择如何计算价值与成本尚待设计，
本轮未宣称已实现主动学习、决策算法或概率校准。

这比“构建语义数据库”更可证伪，也承接性能与 clean code 的目标：
可分配性、执行上下文和职责边界决定哪些共享方式可接受，而不是被综合分数平均掉。
先研究判断是否有用；若有证据支持，再推进 H2 的方案生成/验证反馈，不同时承担所有语言特性的证明问题。

### 后续实验的最小对照提案

| 条件 | 用途 |
| --- | --- |
| 相同证据的普通分析 | 判断结构化协议是否只是换一种提示词表达 |
| 相同证据 + 共同/差异/未知表示 | 测表示本身的作用，固定候选，不混入召回差异 |
| 相同可用证据池 + 通用检索策略 | 作为补证策略对照；允许基线也主动获取材料 |
| 相同可用证据池 + 方案前提驱动补证 | 测是否更有效地使用有限核验预算 |

控制模型、候选、可用证据池、工具权限和资源上限，记录实际 token、检索、人工时间及波动。
固定证据实验与可交互补证实验分开；不能一边给本方法更多材料，一边把增益归于表示。
移除配置、冲突状态或补证策略分别做消融，防止仅靠更多上下文或更长推理获得表面优势。

否定或调整条件：优势只来自额外预算；大量弃答导致有效覆盖明显下降；正确材料下有效而
陈旧/错误材料下失效；人工补全成本超过收益；独立仓库不保持效果；最近邻已覆盖同一机制且无实质差异。
正式阈值在试点后冻结；本轮不给虚构的目标提升百分比。

## 6. 本轮可以与不可以得出的结论

可以：工程底座已有大量可复用材料；A1–A3 的关键增补是证据关联和决策纪律；
值得优先核验一个有成本约束的证据驱动判定机制，而非立即构建大而全平台。

不可以：声称该机制新颖、现有方法在 X-Kernel 已失败、已验证性能/clean code 收益，
或凭阶段文件齐备就认为可以接受实际优化。尚未运行任何对照、消融或真实重构实验。
