# Reflexion Models定义级小实验

日期：2026-11-11。承接[定向精读](2026-11-11-reflexion-confirmation-reading.md)的§3定义与§6解释边界，已实施六个手工可核对输入。本实验是依据论文定义的有限重实现，不是RMTool原工具运行或原论文结果复现。

## 固定方法

给定高层有向关系H、源码关系S，以及源码实体到高层实体的显式映射，将每条源码边的两端映射做笛卡尔积形成E。输出H∩E、E−H、H−E三类；记录每条投影边的原始贡献边，另列未映射边。采用集合语义，不去自环、不做传递闭包。规则顺序及first/all模式必须明确。

限定：实体ID精确匹配，不实现原工具正则／文件属性匹配；两组关系的含义由输入者保证一致，程序不能识别“调用”和“业务职责”被错误混比。没有源码抽取、类型分析或职责分类器。

## 六项已执行检查

| 输入变化 | 预期／实际 |
| --- | --- |
| H={A→B,B→C}；S={a→b,b→a}；a→A,b→B | 符合A→B、偏离B→A、缺失B→C |
| 删除b映射 | 两条源码边未投影，H全部成为缺失；不代表功能真的缺失 |
| a同时有A、C两条规则，first模式 | 只采用A，结果与基本例一致 |
| 相同规则，all模式 | 符合A→B/B→C，偏离B→A/C→B |
| 交换a规则顺序，first模式 | 符合B→C、偏离C→B、缺失A→B |
| 重复源码关系及两个实体映射至同一端点 | 投影边去重，但保留两条不同源码贡献边 |

六项预期由脚本固定后执行，全部匹配；不支持的映射模式拒绝。每次投影检查三类互斥及投影边集合不变量。没有把这六项当独立真实样本或报告检测准确率。
