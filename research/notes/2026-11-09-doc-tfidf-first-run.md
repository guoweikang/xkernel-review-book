# 原生文档TF-IDF基线：首次候选生成

日期：2026-11-09。本轮使用公开实现生成候选，不进行功能重复标注，也不评价重构质量。它不是LDA论文复现，而是后续文档语义方法需要比较的简单检索基线。

## 方法与冻结规则

采用[scikit-learn 1.7的TF-IDF说明](https://scikit-learn.org/1.7/modules/feature_extraction.html#tfidf-term-weighting)和[1.7.2实现](https://github.com/scikit-learn/scikit-learn/blob/1.7.2/sklearn/feature_extraction/text.py)。原始计数乘平滑逆文档频率，再做L2归一化，向量点积得到cosine；数学依据和限制见 `2026-11-09-tfidf-baseline-reference.md`。固定源码副本及SHA256位于 `research/evidence/runs/2026-11-09-tfidf-reference-01/`。

在首次候选运行前写入 `research/protocols/doc-tfidf-discovery-v1.json`：直接文档、不加函数名或祖先上下文，保留Markdown与例子；小写、词unigram、不移除停用词、不拆分标识符、L2归一化。词模式忽略单字符token，不是适合全部语言的分词器。不存在行为等价概率或人工加权总分。

全部2180个输入参与IDF拟合，包括1400个空文档。这样做会影响IDF，不等价于只在780个非空文档上训练；这是冻结的本轮设计，后续若比较另一策略须另立实验。模型只使用本仓库文本而未使用标签，是全库索引，不是独立测试集上的归纳模型评价。

对所有不同对象的无序对计算分数，四舍五入至12位后仅保留正数；分数降序，同分按排序后的对象ID二元组排序。先固定全局top20作为开发审阅队列，归档top100供诊断；不因出现同分或重复主题而事后替换队列。全局top20可能集中于少数主题，当前不声称它覆盖了整个机会空间。

## 实际运行结果

| 项目 | 结果 |
| --- | ---: |
| 输入函数 | 2180 |
| 非零文档向量 | 780 |
| 缺失或空文档 | 1400 |
| 词表规模 | 2084 |
| 全部可能无序对 | 2,375,110 |
| 两端均有非零向量的可能对 | 303,810 |
| 正分对 | 204,459 |
| 冻结审阅队列 | 20对 |
| top20与既有SCC输出重叠 | 1对 |
| 既有156对中两端均有非零文档向量 | 28对 |

正分只表示共享词，不是报告了204459个重复。top20中19对未出现在旧SCC输出，不能叫新增真阳性：SCC有token长度与阈值门槛，两者预算及可用输入不同，尚未进行同预算效果比较。其余128对SCC候选不能由当前直接文档路线同时表示两个端点，也不能据此直接断言语义模型漏检。

top20前15对的cosine在12位精度下为1；这可能来自相同文本，也可能来自相同归一化词频，不证明文本字节相同或代码可以合并。初看名称包含同名构造器、getter、ioctl以及不同对象的操作；没有核查正文契约，所有标签仍是unknown。下一步按原队列核查，不把“文档很像”当作结果。

首次计时约1秒，仅包含本机拟合、全对打分和排序；不含依赖安装、文档采集、文件输出或人工审阅，不能外推为工具端到端成本。

## 实现与检查

脚本为 `scripts/run_doc_tfidf.py`。安装在独立 `.build/doc-retrieval-env`，未改系统Python；固定scikit-learn 1.7.2，实际依赖精确版本写入每次运行的requirements.txt。

微型语料用独立计数／IDF／归一化计算核对库输出；检查同文、无共同词、空文本、单字符零向量、保留否定词和同分排序。控制通过不代表词袋理解否定语义：保留not仅意味着它没有被停用词列表删除。首次01与重复02保留独立报告，固定队列与词表可直接做字节比较。

结果路径：`research/evidence/runs/2026-11-09-doc-tfidf-01/`和`2026-11-09-doc-tfidf-02/`。各保存协议、脚本、控制、词表/IDF、top100、top20、依赖版本和哈希。运行命令：

```sh
.build/doc-retrieval-env/bin/python scripts/run_doc_tfidf.py \
  --output research/evidence/runs/doc-tfidf-new
```

复跑须先在独立环境安装归档requirements.txt，输出目录必须不存在。报告中的耗时不要求字节相同。候选生成是开发实验，无precision/recall、重构收益或创新性结论。

## 下一步的研究决策

对固定20对逐项核查共同功能、已有共享、必须保留的差异、证据不足，记录其是否属于SCC输入门槛之外。首先区分“换输入扩大候选范围”与“在共同可评价范围提高检测能力”。若同文模板或已有委托占主导，保留本轮结果，作为提出文档／结构联合方法的具体失败依据，而不是重排队列制造好结果。
