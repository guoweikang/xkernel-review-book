# P16：610/13 与验证限制定向复核

**来源与阅读范围。**2026-11-05，以 `pdftotext -layout research/evidence/originals/P16-refactorability.pdf /tmp/p16-validation-audit.txt` 提取本地归档，直接阅读 §5.2 Correctness（印刷页1074–1075）、§5.4.6 Threats to Validity（1084–1085）。论文：Nikolaos Tsantalis、Davood Mazinanian、Giri Panamoottil Krishnan，*Assessing the Refactorability of Software Clones*，IEEE TSE 41(11)，2015；[作者原始 PDF](https://users.encs.concordia.ca/~nikolaos/publications/TSE_2015.pdf)，DOI `10.1109/TSE.2015.2448531`。作者 URL 来自本仓库归档 manifest；本轮未联网、未打开作者结果工件、未复现实验，不承担 §3 机制审阅。

## 分母与验证流程（§5.2）

- 正确性实验只选 **36 个数据集（9项目×4检测器）中的一个：JFreeChart 1.0.10 / Deckard**。仅分析 `src` 生产代码，排除 experimental、swt、test。Deckard 报告 **2,306 对方法级克隆**，其中方法判为可重构 **1,091 对**；其中 **610 对**至少一个片段被既有单测部分或全部覆盖，进入重构验证。项目 src 覆盖率为 **54.4%**，不是“610 对全部语句均已覆盖”。
- 逐对流程：先用 Eclipse Extract Method 抽成两个方法，再执行作者克隆重构；无编译错误时运行项目完整测试套件；随后撤销该对的变换，恢复原始状态。**610 是单独尝试的克隆对数量，不是一次累计重构的610处、610个测试或全部可重构样本。**项目选择还要求原测试套件无失败、较高覆盖及能测试继承层次重构。
- **610/610 初次均无编译错误；其中13对重构引发序列化相关测试失败。**13 的分母是已筛选且有测试覆盖的610次重构，不是测试总数，也不是2,306或1,091。作者修正后重做这13对并报告全部测试成功，随后总结610对均成功；不能写成“原实现首次610/610编译与测试均通过”，也不能写成独立新测试集上的610/610。

## 序列化失败与作者修正（§5.2，页1075）

涉及 `CombinedDomainXYPlot`、`CombinedRangeXYPlot`，共同父类为 `XYPlot`。克隆访问子类中同名同类型字段，重构将这些共同访问字段上移至父类；**从子类删除字段破坏序列化类契约，使已有序列化对象反序列化失败**。这说明编译通过未覆盖持久化兼容性，并非一般“类型不匹配”。作者修改变换机制：当相关类实现 `Serializable` 时，不再上移共同访问的 **non-transient** 字段，而对每对字段给抽取方法引入参数，像字段名称不同那样处理；随后重做13对，测试全部通过。不能把这一具体修正泛化为已解决所有序列化兼容问题。

## 哪些仍是限制（§5.2、§5.4.6）

- **验证集兼作开发反馈。**实验由末位作者执行、与首位作者讨论，持续两个月；检查失败后还扩展了前置条件（文中举 #3/#4），序列化机制亦经本批测试修正。论文这两节未报告冻结实现后的独立留出验证；不能把最终结果当作未经调试的独立准确率。
- **测试通过不证明普遍等价或前置条件完备。**作者在 §5.4.6 将前置条件不完整列为威胁，以610对结果缓解，并表达完整性的信心；这是作者判断，不是形式证明。使用开发者手写测试；“自动生成测试不会改变失败结论、可能扩大覆盖”是作者推测，本轮未见对应实验。
- **并发未验证。**作者明确未在使用 synchronized 方法/语句的并发 Java 程序上测试前置条件；加入线程同步、通信依赖是可扩展方向，不是已完成验证。更不能据此推断 Rust 所有权、内核并发或跨配置安全。
- **检测器与外推边界。**各检测器的最小规模、相似度和标识符归一化定义不同；默认/推荐设置只能缓解可比性问题，设置变化仍会影响检出集合。作者承认不能直接推广到未考察项目/检测器。九项目的大规模分析不能替代仅单项目610对的变换正确性实验。

**建议引用句。**“在 JFreeChart 1.0.10 经可重构判断及测试覆盖筛选的610对克隆上，作者报告首次均可编译，其中13对触发序列化回归；调整字段处理机制并重测失败对后全部通过既有测试。该结果支持指定样本和测试范围内的验证，不证明前置条件完备、并发正确或普遍行为等价。”实际查询词为 `5.2`、`5.4.6`、`610`、`13`、`serializ`，仅在上述 PDF 转文本和归档 manifest 内检索。
