# 工具与模型：发现、生成、比较的边界

2026-11-11。定向阅读 Librarian v3 §§3、5、6.2，并补读§6的 MDL 定义；Agentless 仅核对官方 main README（浮动版本，未固定 SHA）。未运行实验、未核查本地实现。以下是文献事实与拟议流程，不是通用能力边界或新颖性结论。

## 已发表方法，不等于我们的设计

- **Librarian**：§3 输出共享库与改写后的调用方，以保留原先通过的测试集合约束候选；§5 用模型生成摘要、embedding 聚类，再采样多个重构并重排。因此其发现/分组不是无模型流程。§6 的 MDL 使用语言模型负对数似然，不能归为纯静态、model-free 指标。§6.2 的14名参与者提供129次偏好判断；MDL相对MI的偏好达到显著性，不代表对所有任务或指标普遍胜出。[固定 v3：§§3/5/6/6.2](https://arxiv.org/html/2506.11058v3)
- **Agentless**：README 描述定位→候选补丁生成→测试验证与重排；Setup 明确要求模型 API key。“agentless”不等于“无LLM”，也不是功能重复检测方案。本轮只核对其流程声明，不引申为已验证的 Rust 重构系统。[官方 README：About / Setup](https://github.com/OpenAutoCoder/Agentless/blob/main/README.md)

## 我们拟采用的边界（遵循不做自动 LLM detector 的要求）

| 环节 | 拟议职责与输出 | 不作的声称 |
| --- | --- | --- |
| 生产候选发现 | 不使用生成式 LLM 扫描、生成摘要或裁定重复；由固定规则、源码结构/token/文档检索产出候选及可追踪分数。 | 候选命中不是功能重复真值，也不是自动重构授权。 |
| 证据检索 | 工具取得固定源码、调用/使用关系、已有 helper、测试及配置事实，注明解析/编译覆盖和缺失。 | 找不到边不等于没有委托；文档声明不等于运行事实。 |
| 方案生成 | 人工选定候选后，模型可提出保留现状、复用已有 helper、抽取小机制等备选，同时列条件与风险。 | 模型不反向生成“证据”填补缺口，不将建议计为已发现机会。 |
| 比较与验证 | 工具报告 diff、接口/调用方变化、构建/测试/针对性性质检查；按同一输入与约束比较备选，包括不改方案。模型可解释权衡。 | 测试通过不是全行为等价；更短、MDL更低或模型偏好不是维护收益证明。 |
| 决策 | 人依据证据覆盖、行为差异与维护成本决定是否实施；允许拒绝抽象、保留重复或待补证据。 | 模型 judge、Agent 复核、多人模型投票均不充当独立人工标签或 ground truth。 |

**模型仍须如实标记。** embedding 即使封装成固定工具 API，仍是学习模型，不可称“无模型检索”；本轮不将其默认纳入生产发现。若以后单列非生成式 embedding 实验，应固定模型/版本/输入并与规则基线分开。MDL亦需区分计数/编码方案与 Librarian 的模型似然实现；似然评分不是自由文本 judge，但仍依赖模型。这里约束的是我们的工作流与证据职责，而非宣称工具永远优于模型、模型不能检测，或文献已经证明上述分工最佳。
