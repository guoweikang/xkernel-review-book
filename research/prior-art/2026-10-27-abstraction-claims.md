## 权项核对

### S1：可变点元数据不等于生成参数化公共实现

以下均据 [S1 权1–20](https://patents.google.com/patent/US9519464B2/en#C1)。

| 层次 | 技术限定及依赖 |
| --- | --- |
| 独立权1；独立系统权12 | 基于方法调用取得片段组，选择代表片段，生成至少指示一个可变点的元数据，将代表片段与元数据关联存入知识库。 |
| 权2→1；权3→2；权4→3；权6→2 | 调用驱动抽取；相关变量与数据依赖语句；间接数据依赖；控制流相关语句。系统对应权13–16。 |
| 权8→1；权9→8 | 标识符 token 化后的语句序列决定形状分组；至少考虑子组大小选择代表；由同子组片段差异确定可变点。系统对应权18、19。 |
| 权7→2；权11→1 | 抽取片段内部去除语法相同克隆；API 用法关联是附加限定。系统对应权17、20。 |

技术边界：独立项没有要求生成共享函数、替换各调用方或执行验证闭环。依赖抽取用于片段形成，不能直接当作重构前后依赖保持检查；可变点记录也不能直接等同于泛型、trait 或回调参数合成。API 用法不应反向缩窄独立权1。旧笔记的知识库定位基本成立，但以“不含 PR”区分已不适合当前研究目标。

### S2：重构可行性估计与用户反馈，区别于变换验证

以下据 [S2 权1–20及说明书相关段落](https://patents.google.com/patent/US20110246968A1/en#C1)。

| 层次 | 技术限定及依赖 |
| --- | --- |
| 独立权1 | 用户输入参与选择目标片段；在一个或多个代码库识别克隆组；估计改进潜力、排序并展示。 |
| 独立权12 | 存储介质；用户参与选择片段及按相似度阈值识别克隆。不应附加权1的潜力排序步骤。 |
| 独立权16 | 存储介质；取得真/近克隆组，估计并展示改进潜力。排序另在权17→16。 |
| 权2–6均→1；权20→16 | 权2规范化与哈希索引；权3指定相似度及阈值；权4粗/精匹配；权5缺陷潜力；权6、20重构候选可行性估计。 |
| 权10、11均→1 | 用户确认免检及排除免检片段；不是自动等价验证。 |

说明书还描述差异分类驱动的重构潜力，以及用户标记确认缺陷/重构机会后改进估计器；不能概括成“没有反馈”。但这些描述不等于生成补丁后由编译、测试或反例驱动接口修正。已读权项未明确生成公共实现或参数化差异。多代码库入口已有明确文本，不能用“面向全仓”本身区分。权1关于真/近克隆的连接措辞与权16不同，本批不作法律解释。

### S3：直接生成共同部分与差异部分

以下据 [S3 权1–11](https://patents.google.com/patent/US20250362905A1/en#C1)。

| 层次 | 技术限定及依赖 |
| --- | --- |
| 独立装置权1 | 从软件的多个程序集合的至少一部分，由语言模型按特征相似性提取代码块组，再生成公共块及对应原块差异的多个部分块。 |
| 独立方法权10；独立装置权11 | 权10另明确取得生成结果；权11以包含代码块和抽取/生成指令的输入文本及取得结果限定过程，不能只用权1概括。 |
| 权2、3、4均→1 | 分别增加利用公共块保持对应功能等价、组为一对、特征含程序逻辑结构。 |
| 权5→1 | 将生成的公共/部分块与组外程序一起再次抽取和生成。 |
| 权6、7均→1 | 公共函数＋调用它的部分块；或公共类＋继承它的子类。 |
| 权8、9均→1 | 分别限定合并指令输入，或先抽取组再输入生成指令的流程。 |

权2是输出功能等价要求，未明确验证器、失败反例或修复循环；权5是迭代抽象，不能改述为验证反馈。说明书也有逐步处理整个目标软件的描述。因而“LLM＋多实现公共骨架＋保留差异”已有直接相邻技术；具体 Rust 参数化和跨配置约束机制仍需单独对照。

下表是对上述权项的工程比较，不是把三份文本拼接成法律判断。“待核”指当前研究还需具体化和核验，不是认定已有技术缺失。

| 比较维度 | 可追溯的已公开技术位置 | 当前研究必须继续区分的问题 |
| --- | --- | --- |
| 全仓库公共抽象 | S2的多代码库分析；S3权1、5的程序集合及迭代生成 | 检索范围、共同职责发现与可迁移公共接口是不同任务；不能只把片段单位改名为 crate/mod。 |
| 可变点参数化 | S1权8、9的形状与差异元数据；S3权6、7的函数/类复用形式 | 可变点如何成为类型、值、回调或组合边界；哪些差异不能安全参数化，哪些仍未知。 |
| 重构约束 | S1依赖抽取；S2可行性估计；S3权2等价要求 | 所有权、生命周期、别名、副作用、并发、配置和依赖边界如何成为可检查的变换前置条件，不能用一个评分替代。 |
