# 原始资料与可追溯性

本目录保存研究来源的本地副本。`manifest.json` 记录实际下载时间（UTC）、原始 URL、
最终 URL、文件路径、字节数和 SHA-256，失败则保留失败状态与原因。

- 这些是 2026-10-27 整理时重新取得的副本，不冒充之前浏览工具返回内容的逐字存档。
- 来源的初次检索/阅读范围见 [SOURCES](../SOURCES.md)，分析见相应专题笔记。
- 下载成功不代表已阅读全文或完成复现；论文结论仍以所列阅读深度为限。
- 动态产品页面以抓取时间为准；xerj 源码取固定 commit。源页面发布日与抓取日分开。
- 哈希用于检查副本完整性，不是可信时间戳、权属证明或法律意义上的公证。
- 后续新版本另存新文件并增加清单记录，保留旧证据，不静默替换已引用的副本。
- 此目录尚未形成完整网页镜像、所有专利族、完整实验环境或完整 xerj 源码归档。

当前来源台账中的稳定编号用于连接原始资料与结论。没有本地副本的条目仍保留 URL
及阅读记录，不能因下载失败或当前缺失而从台账中删除。
