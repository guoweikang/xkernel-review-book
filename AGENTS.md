# Research work

When continuing this repository's research, read `.agents/skills/research-execution/SKILL.md` and follow the relevant experiment protocol. Use `research/PROGRESS.md` to resume and the topic synthesis to assess relevance. A completed substep does not require user confirmation if the next bounded step is already authorized.

Preserve original runs, distinguish plans from measurements, and register new research Markdown in `research/catalog.json`. Run `python3 scripts/check_research_catalog.py`, the changed experiment's checks, and book build/link validation before handing off substantive updates.
